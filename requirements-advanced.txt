# Heavier requirements — only needed from Sprint 3 onward
# (imaging CNN, federated learning, explainability).
# These are split out so early sprints don't force a slow install.
# Install with: pip install -r requirements.txt -r requirements-advanced.txt
#
# NOTE: torch is large — for the imaging CNN (Sprint 3) and federated
# simulation (Sprint 5), prefer running on Google Colab (free GPU)
# rather than a laptop CPU.
#
# torch/torchvision are pinned to their BASE versions. The working environment
# has 2.13.0+cpu / 0.28.0+cpu, but a "+cpu" local version tag only resolves
# against the PyTorch CPU wheel index, not PyPI -- pinning it verbatim would
# make this file uninstallable on Linux/CI. To get the CPU wheels explicitly:
#   pip install -r requirements-advanced.txt \
#       --extra-index-url https://download.pytorch.org/whl/cpu

# Deep learning (Sprint 3-4: imaging + fusion model)
torch==2.13.0
torchvision==0.28.0

# Federated learning simulation (Sprint 5)
#
# The `simulation` extra, not bare `flwr`. src/federated/server.py imports
# `ray` directly (flwr.simulation runs the simulated hospital clients on it),
# and the bare install does not carry it -- so `pytest` could not even collect
# tests/test_federated.py in a clean environment, which is why every CI run
# from 2026-08-24 onward failed at collection with
# `ModuleNotFoundError: No module named 'ray'`. It passed locally only because
# ray happened to be installed there.
#
# The extra pins ray itself, so it is not repeated here: flwr 1.33.0 requires
# ray==2.55.1 on Python 3.11, which is the version the reported federated
# result (98.75% vs 100% centralized) was measured with.
flwr[simulation]==1.33.0

# Explainability (Sprint 6)
shap==0.51.0
